Connect MT5

The web app does not need your MT5 password. The EA runs inside your own MT5 terminal and uses this access key to identify your account.

MT5 EA setup
  1. Open MT5 → MetaEditor.
  2. Open the GoldSpotSignalBridge EA from this project.
  3. Set AccessKey to your same key.
  4. Set ApiBaseUrl to this website URL.
  5. In MT5 allow the website URL under Expert Advisors → WebRequest.
  6. Attach the EA to your XAUUSD chart.

Connect MT5

Gold analysis works without MT5. Connect MT5 only when you want your real balance, equity, positions, broker data, and live order execution. Your MT5 credentials are sent to the server and used only to configure the MetaApi cloud connection.

MetaApi connection
  1. Enter your broker, MT5 server, login and password.
  2. Tap SAVE MT5 DETAILS.
  3. The server sends the account to MetaApi and waits for the broker connection.
  4. When MetaApi reports CONNECTED, your real account data and broker-specific market data become available.

Your MetaApi API token stays on the server as an environment variable; it is never placed in this page.
